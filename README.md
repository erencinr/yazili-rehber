# Yazılı Rehber

OYSS rehber ve yazılıya hazırlık sitesi. Next.js 16 + Tailwind, içerik `data/` altındaki JSON dosyalarında.

## Çalıştırma

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # üretim derlemesi (veri ve puan kontrolleri burada çalışır)
```

Marka adı ve site adresi: `src/config/site.ts` (`NEXT_PUBLIC_SITE_URL` ortam değişkeniyle de verilebilir).

Ayrıntılar için `CLAUDE.md` ve `docs/`.
